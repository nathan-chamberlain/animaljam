# Farm Rogue

A top-down pixel roguelike where you play as a farmer breeding animals on farmland while defending against escalating predator waves with a shotgun, dash, turrets, and a scroll-wheel hotbar.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:8080

## Controls

| Input | Action |
|-------|--------|
| WASD | Move |
| Space | Dash (brief invincibility) |
| Mouse click | Shoot / place item |
| Scroll wheel | Switch hotbar / turret type |
| 1–3 | Select hotbar slot |
| U | Upgrade shop (between waves) |

## Gameplay

- **Breed animals** — Two or more livestock breed automatically. Upgrade tier in the shop to convert all animals and earn more per breed.
- **Defend the farm** — Predators spawn in waves. Use guns, hose turrets (push), and unlockable turrets to fight back.
- **Progression** — Upgrade livestock tier, gun tier, and unlock pea shooter / snipe tower turrets in the shop.
- **Lose condition** — If all animals are eaten, the run is over.
